# Player-Two
We made a pong game you play against a bot. We decided to use the toy neural network library because it was the most beginner friendly and suited our needs the best. 

We first made the dots that make up the grid of the game along with the ball the user will play with. Then in order to play the game we made paddles the user could move up and down, and made the ball move and bounce off the top and bottom of the board along with bouncing off the paddles.
